# BROZA — Premium Unisex Streetwear E-Commerce Storefront

> **"Wear Your Identity."**  
> Engineered in Kanhangad, Kerala, India. Since 2026.

BROZA is a high-end, cinematic static frontend web application for an independent unisex streetwear and apparel label. Built with React, Vite, Tailwind CSS, and GSAP ScrollTrigger, it transforms the brand's Instagram identity (`@broza.str`) into a state-of-the-art editorial storefront.

---

## ⚡ Tech Stack & Architecture

- **Core:** React 19, Vite 8, JavaScript (ESM, JSX)
- **Styling:** Tailwind CSS v4, Modular Modern CSS, Custom Glassmorphism, Neon Gradient Tokens
- **Animation System:** GSAP 3, GSAP ScrollTrigger, Staggered Timelines, Parallax Transformations
- **Icons:** Lucide React + Custom Standalone SVG Components
- **Typography:** Space Grotesk (Display Headlines), Plus Jakarta Sans (Body), Syne (Accents)

## 🚀 Key Website Features

1. **Cinematic Hero Section:**
   - Word-by-word headline reveal: *"WEAR YOUR IDENTITY."*
   - Editorial streetwear model composition with slow-spinning circular gradient brand mark.
   - Live location pill: *KANHANGAD, INDIA*.

2. **Featured Collection ("THE NEW STANDARD"):**
   - Dynamic category filter tabs: *All Releases*, *Oversized Tees*, *Hoodies*, *Unisex Bottoms & Shirts*.

3. **Product Quick-View Modal:**
   - Interactive zoom imagery, gallery selector, size picker (S, M, L, XL, XXL).

6. **Shop by Discipline (Categories):**
   - Visual blocks for *T-Shirts*, *Hoodies*, and *Unisex Collection*.
   - Smooth hover zoom and instant category filtering on click.
7. **Campaign Banner:**
   - *"THE NEXT DROP IS HERE"* with active real-time countdown timer.
   - Oversized watermark typography.
8. **About BROZA:**
   - 4 Brand Pillars: *Unisex by Design*, *Heavyweight Caliber*, *Kanhangad Roots*, *Limited Releases*.
   - Since 2026 heritage seal.
9. **Instagram Movement Section:**
   - Responsive 6-tile lookbook grid linking to [@broza.str](https://www.instagram.com/broza.str/?hl=en).
   - Hover stats with likes, comments, and post preview.
10. **Client-Validated Newsletter:**
    - *"STAY IN THE LOOP."* with real-time regex validation and animated success state.
11. **Footer:**
    - Kanhangad studio address, all-India express delivery notice, quick links, copyright, and smooth back-to-top button.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Development
```bash
# Clone or navigate to the project directory
cd d:/broza

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
